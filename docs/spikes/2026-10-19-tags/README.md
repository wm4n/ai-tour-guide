# KittenTTS 2 標記實測（2026-10-19）

目的：試聽回饋「像在念稿」，想知道 KittenTTS 2 的 `<pause>`、`[情緒]`、`(((強調)))` 能不能用來控制停頓與語氣。
環境：複製聲音 F2、中文、`normalize=False`、每種 2 個 seed（1234、42）。腳本：`tags_probe.py`
（Whisper 轉寫前先把標記字樣從原稿拿掉；`停頓` 是能量低於 -40 dB 且長於 0.15 秒的區段）。

| 版本 | 結果 |
|---|---|
| A 無標記（對照） | 句間停頓 0.16～0.26 秒；seed 42 把「紅磚」唸成「董宏磚」，CER 0.67 |
| B 句後加 `<pause>` | 停頓確實變長（0.74、1.7 秒），但模型會**發出一個聲音**，Whisper 轉成「棗炮」「泡」，兩個 seed 都有 |
| C 句首 `[contemplative]` | 音訊被**截斷**（只念到第一句，2.8 秒），CER 0.77～0.83，不可用 |
| D `(((兩百年)))` | 一個 seed 正常、一個被截斷，不穩 |
| E `<pause>` + `[contemplative]` | 沒被截斷，但仍有怪聲（「吳朝」「上上看」） |

## 結論
- 這四種標記在中文＋複製聲音上都不穩定，**不採用**；套件說明本來就標示為 Beta。
- 停頓維持我們自己控制：稿子的空行 → 管線在合成單位之間插入靜音（`paragraph_gap_seconds`、`gap_seconds`）。
- 樣本很小（每種 2 個），只能說「現在不敢用」，不能說「永遠不行」；若之後套件改版再測。
