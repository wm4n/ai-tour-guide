# iPhone 實機驗收清單（issue #8、#10、#11）

模擬器驗不到、**必須在 iPhone 14 Pro 實機上做**的項目。這些項目**都還沒有驗過**——程式面的準備（背景模式、
Always 權限請求、鎖定畫面資訊、各項流程與單元／模擬器端到端測試）做完了，不代表實機行為正確；
這份清單是要你出門前或走一趟時照著驗、並把結果填回來。
填完請把結果貼到對應 issue 的留言，agent 再據此關單或修正。

> 這個 repo 是公開的：填結果時不要寫主機位址、Tailscale 名稱、token。

## 0. 準備

- [ ] 用 Xcode 把 App 裝到實機（`app/` 的 `flutter run --release -d <iPhone>`，或從 Xcode 開 `ios/Runner.xcworkspace`）。
- [ ] 主機在家裡開著，**已用 `--max-llm-calls N` 啟動（真實模式）**；手機連上 Tailscale。
      ⚠️ 真實模式每次呼叫都消耗 Claude Pro 額度；下面的問答、拍照項目請先決定要用幾次（建議各 1～2 次）。
- [ ] App 設定好主機位址與 token，畫面顯示「主機已連線」。

## 1. 背景行為（#8）

按「出發」時依序會跳出權限詢問。

| 項目 | 怎麼確認 | 結果 |
|---|---|---|
| 定位權限先選「使用 App 期間」，隨後跳出「是否改成永遠」 | 對話框選「保留使用 App 期間」或「改為永遠允許」都可以；選「永遠」才是目標 | ☐ 永遠　☐ 只有使用期間 |
| 只有「使用期間」時畫面有紅字提醒；到「設定 → Buddy Tour → 位置」改成「永遠」後回到 App，紅字消失 | 出發後看畫面；改完回到 App | ☐ 有、也會消失　☐ 沒有　☐ 不會消失 |
| 螢幕鎖定、手機放口袋走 **15 分鐘以上**，位置仍持續回報 | 主機日誌 `POST /v1/tour/location` 約每 10 秒一筆，沒有長時間中斷 | 最長中斷：＿＿ 秒 |
| 鎖定期間走到景點旁，**自動播出**介紹 | 戴耳機聽 | ☐ 有　☐ 沒有 |
| 鎖定畫面顯示目前播放的景點名稱 | 亮屏看鎖定畫面 | ☐ 有　☐ 沒有 |
| 鎖定畫面／耳機的**暫停鍵**有效：暫停主動介紹，再按恢復 | 播放中按、兩段之間也按 | ☐ 有效　☐ 無效 |
| 播放時其他 App（音樂、Podcast）**調小聲**，播完恢復 | 先開音樂再出發 | ☐ 是　☐ 否 |
| 耗電 | 100%（或接近）出發、鎖屏走 15 分鐘，記電量；同樣條件再來一次不開 App 當對照 | 開 App：＿＿ %／15 分鐘　對照：＿＿ % |

## 2. 語音問答（#10）

| 項目 | 怎麼確認 | 結果 |
|---|---|---|
| **本機 zh-TW 辨識是否可用** | 按住說話，看按鈕下方標示是「本機辨識」還是「線上辨識（語音會送到 Apple）」 | ☐ 本機　☐ 線上 |
| 麥克風與語音辨識權限對話框正常，拒絕時有清楚的提示 | 第一次按住說話；也試一次在「設定」關掉權限 | ☐ 正常 |
| 放開後**立刻**聽到填空短句（「好，我來查一下」） | 計時或憑感覺 | ☐ 立刻　☐ 有延遲約＿＿ 秒 |
| 答案**一段一段**播出，第一段不要等太久 | 問「那間廟拜的是誰」之類 | 問完到第一句真正的答案：＿＿ 秒（目標 ≤ 10 秒，不是過關條件） |
| 發問時正在播的介紹**暫停**，答完從**被打斷那一句的開頭**接著講 | 介紹播到一半時按住說話 | ☐ 是　☐ 從頭　☐ 從中間 |
| 問「再多說一點」會接著剛講的那段 | 介紹播完後問 | ☐ 是　☐ 否 |
| 需要上網的問題先說「我上網查一下」 | 問「這間店現在有開嗎」 | ☐ 是　☐ 否 |
| 錄音與播放切換後，其他 App 的音量能恢復 | 問完看音樂有沒有恢復 | ☐ 恢復　☐ 一直被壓低 |
| 主機端記錄的延遲 | 看主機 `~/.buddy-host/qa-latency.jsonl` 與旅程報告的 `qa` 區塊 | 平均：＿＿ 秒 |

## 3. 拍照提問（#11）

> 這一項會真的呼叫 Claude 看圖（每次約 50k～80k 輸入 token），**請先決定次數**。

| 項目 | 怎麼確認 | 結果 |
|---|---|---|
| 相機權限對話框正常，拒絕時有提示 | 第一次按「拍照問」 | ☐ 正常 |
| 拍照後主機收到照片，Claude **真的看得到照片**並答對 | 拍一個招牌或建築，問「這是什麼」 | ☐ 答對　☐ 答非所問　☐ 說看不到照片 |
| 回答有結合位置與指南針方向（例如「你左手邊那棟」） | 聽答案 | ☐ 有　☐ 沒有 |
| 照片只在主機 `~/.buddy-host/photos/`，檔案權限只有本人 | `ls -la ~/.buddy-host/photos/` | ☐ 是 |
| 隔天（超過 24 小時）照片已被清掉 | 再看一次資料夾 | ☐ 是 |
| 如果 Claude 說讀不到照片 | 看主機日誌與 `usage.jsonl`；這很可能是 `--tools`／`Read(//…/photos/**)` 規則的問題（尚未用真實 Claude 驗證過） | 錯誤訊息：＿＿ |
