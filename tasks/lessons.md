# Lessons

- Android 執行方式要先區分模擬器與實機：Android 模擬器連本機後端用 `http://10.0.2.2:8000`；實機才需要改成同網段 Mac LAN IP。
- 只用 mock 測過的外部 API 整合不算驗證：公共 Overpass 會過載、真實資料有行政區標籤與街邊設施，這些只有打到真實服務才看得到。
- 要求使用者提供機密（token）時，指令要在使用者自己的終端機執行；`! <command>` 會把輸出（含 token）印進對話。
- 把規則寫進 LLM 的提示時，範本裡不能示範被禁止的寫法。

## 2026-10-19 驗收指標的誤判要先看轉寫，不要先加重試
- 開場句連換 10 個 seed 都不過，我先加 seed（治標）；直接讀 log 裡的轉寫才發現是 Whisper 把「隍」寫成同音的「黃」，指標本身誤判。
- 規則：驗收一直失敗時，先逐筆看「期望 vs 轉寫」，分辨「真的唸錯」與「指標誤判」，再決定加重試還是修指標。
- 長時間背景驗證若第一筆結果已經不對，就停掉、改成只跑最小的單句重現，不要等整份跑完。
